# MLSC-MITAOE Website — Futuristic Edition

A responsive multi-page website for Microsoft Learn Student Club, MITAOE, built with HTML, CSS and vanilla JavaScript.

## Pages
- Home
- Core Committee
- Teams overview
- Tech Team
- PR Team
- Finance Team
- Management Team
- Social Media Team
- Events (Inauguration and Edgeler)
- Contact
- Objectives
- Join Us

## Run locally
1. Extract the ZIP file.
2. Open the extracted `MLSC-MITAOE-Website` folder.
3. Double-click `index.html` to open it directly in your browser.
4. Keep all HTML files, `styles.css`, `script.js`, and the `assets` folder together.

## Customization
- Replace `assets/mlsc-logo.jpg` and `assets/mitaoe-campus.jpg` to update the official logo and campus image. Keep the same filenames.
- Update event dates and registration details in `events.html` when confirmed.
- Core committee cards intentionally use abstract placeholders; no personal photos are included.
- The contact form opens the visitor's email application using `mailto:`. It does not store messages. Connect a backend or form service before using it to collect submissions online.
- `design-references/` contains the supplied dashboard reference images.

## Publishing
This ZIP is a local website project. To make it publicly accessible, upload the folder to a static hosting service such as GitHub Pages, Netlify or Vercel.
